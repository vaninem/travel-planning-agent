# 旅行安排与常见约束

## 雨天和临时调整

雨天、暴雨或降雪时优先寻找室内博物馆、美术馆、科技馆或室内展览。天气预报超出覆盖范围时，先给户外活动留备选。关闭、暂停开放、预约变更以场馆最新公告为准。

## 亲子、老人和步行体力

亲子出行和老人同行适合减少跨区移动，留出休息、用餐和卫生间时间。同一天优先围绕相近的景点，中间预留排队和换乘缓冲。无障碍设施以场馆或公共交通运营方公告为准。

## 住宿与预算

住宿位置可以优先考虑交通方便、离首日及末日活动区域都较近的地点。酒店地点服务可用于定位与找附近候选，房价、房型、库存及退款条件需向酒店或预订平台确认。车票和门票也应以运营方报价为准。
